# Макет сайта «Добро и Тортики»

[Посмотреть макет на GitHub Pages](https://signatureq.github.io/dobro-i-tortiki-maket/).

Откройте `index.html` в браузере. Для локального просмотра через сервер: `python3 -m http.server 8000`, затем `http://localhost:8000/`.

Это визуальный макет для согласования, а не сайт на Тильде. Композиция блоков, фотосетки, карточки, аккордеон и анимации ориентированы на главную страницу [Зарни Ань](https://ekb.zarny.ru/). Фон сделан светлее, бирюзовые акценты заменены розовыми. В макете используется присланный клиенткой логотип `assets/client-logo.jpg`, а четыре направления взяты из переписки. В `assets/photos/` — 26 выбранных и уменьшенных для сайта фотографий из предоставленного архива мастер-класса. Снимки одного события используются также как пример для других направлений до получения отдельных фотосессий.

## Что заменить перед запуском

- Фотографии для курсов и выездных мероприятий — на кадры именно этих форматов, когда они появятся.
- Описание программ — на утверждённые условия: возраст, длительность, стоимость, состав занятий, расписание.
- Блок отзывов — на настоящие отзывы с разрешением на публикацию.
- Ответы на вопросы — на подтверждённую информацию.
- Контакты и способ записи — на данные школы.
- Ссылки Telegram, ВКонтакте и MAX в первом экране — на реальные аккаунты администратора. Сейчас кнопки показывают пометку макета.
- Тексты макета — на финальные тексты, которые обещала прислать клиентка.

Форма в этом макете демонстрационная: введённые данные не отправляются и не сохраняются.

## Перенос на Тильду

| Секция макета | Как собрать в Тильде |
|---|---|
| Шапка и первый экран | Zero Block для композиции; меню с якорями |
| Польза и этапы | Zero Block или карточные блоки |
| Четыре направления | Карточки услуг с переходом к форме/подробным страницам |
| Атмосфера и галерея | Фото-блоки с реальными изображениями |
| Отзывы | Блок отзывов после получения текстов |
| Вопросы | Блок «Аккордеон» |
| Запись и контакты | Форма Тильды, мессенджеры и юридические тексты после получения данных |

Шрифты `Neucha` и `Manrope` и палитра описаны в `styles.css`. Лицензии шрифтов находятся в `assets/fonts/licenses/`. Макет адаптирован под десктоп и мобильный экран.

Декоративные элементы лежат в `assets/decor-*.svg`. Плавное появление при прокрутке задано в `styles.css` и `script.js`; при настройке анимаций в Тильде это ориентир по длительности и порядку появления элементов.
