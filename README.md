# Добро и Тортики — визуал сайта

[Открыть сайт](https://signatureq.github.io/dobro-i-tortiki-maket/).

Статический снимок семи страниц, подготовленный для просмотра клиенткой. Включает новый портрет Анастасии, фотографии школы, отзывы из предоставленного документа, карусель анонсов и форму мастер-классов.

Форма демонстрационная: заявки не отправляются и не сохраняются. Рабочая отправка и редактор подготовлены в отдельной серверной версии.

Публикация использует относительные пути и размещается в GitHub Pages из ветки main. Серверные исходники, доступ к редактору, база и заявки сюда не включены.

Фотографии предоставлены клиенткой. Происхождение изображений сохранено в assets/photo-sources.json и метаданных файлов. Лицензии шрифтов — в assets/fonts/licenses/.
